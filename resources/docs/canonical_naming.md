# 规范命名规则

## 目标

保证 Concept.canonical_name 全局唯一、可复用、可检索。

## 核心规则

1. 主名取教材原语言，其他语言放 aliases。
2. 创建前先搜索，命中相同或同义概念优先复用。
3. 同名不同义必须加限定词。
4. 粒度保持条目级，一个名称对应一个可解释概念。

## 正反例

正确：

- canonical_name: 反馈
- aliases: [feedback, 反馈机制]

错误：

- canonical_name: feedback
- aliases: []

## 歧义处理

- 稳定性（控制系统）
- 稳定性（化学）
- 稳定性（经济学）

## 批量导入检查

1. 搜索命中后复用 canonical_name。
2. 未命中再创建新节点。
3. 每批导入后检查重复别名和空定义。
